# 테이블오더 서비스 - 사용자 페르소나

---

## Persona 1: 고객 (Customer)

| 항목 | 내용 |
|------|------|
| **이름** | 김민수 (대표 고객) |
| **역할** | 매장 방문 고객 |
| **연령대** | 20~60대 (전 연령층) |
| **기술 수준** | 다양함 (스마트폰/태블릿 기본 사용 가능) |
| **목표** | 빠르고 편리하게 음식을 주문하고, 주문 상태를 확인하고 싶다 |
| **동기** | 직원 호출 없이 원하는 시간에 즉시 주문, 대기 시간 최소화 |
| **불만 요소** | 복잡한 UI, 느린 응답, 주문 누락, 이전 고객의 주문 내역 노출 |
| **사용 환경** | 매장 테이블에 설치된 태블릿 (브라우저 기반) |
| **핵심 니즈** | 직관적 메뉴 탐색, 간편한 장바구니 관리, 빠른 주문 확정, 주문 상태 확인 |

## Persona 2: 매장주 (Store Owner)

| 항목 | 내용 |
|------|------|
| **이름** | 박영희 (대표 매장주) |
| **역할** | 매장 소유자 및 최고 관리자 |
| **연령대** | 30~50대 |
| **기술 수준** | 중간 (기본적인 웹 서비스 사용 가능) |
| **목표** | 매장 운영을 효율적으로 관리하고, 매출과 주문 현황을 실시간으로 파악하고 싶다 |
| **동기** | 인건비 절감, 주문 오류 감소, 운영 효율성 극대화 |
| **불만 요소** | 복잡한 관리 도구, 실시간 정보 부족, 메뉴 변경의 어려움 |
| **사용 환경** | 매장 내 PC 또는 태블릿 (브라우저 기반) |
| **접근 권한** | **전체 기능** - 주문 관리, 테이블 관리, 메뉴 관리, 과거 내역 조회, 직원 계정 관리 |
| **핵심 니즈** | 실시간 주문 모니터링, 메뉴 CRUD, 테이블 세션 관리, 과거 주문 이력 조회 |

---

## Persona 3: 매니저 (Manager)

| 항목 | 내용 |
|------|------|
| **이름** | 이준호 (대표 매니저) |
| **역할** | 매장 운영 매니저 |
| **연령대** | 25~40대 |
| **기술 수준** | 중간~높음 |
| **목표** | 매장 현장 운영을 원활하게 관리하고, 주문 처리와 테이블 회전을 효율적으로 하고 싶다 |
| **동기** | 원활한 매장 운영, 고객 만족도 향상, 주문 처리 속도 개선 |
| **불만 요소** | 주문 누락, 테이블 상태 파악 어려움, 메뉴 변경 지연 |
| **사용 환경** | 매장 내 PC 또는 태블릿 (브라우저 기반) |
| **접근 권한** | **주문 관리 + 테이블 관리 + 메뉴 관리** - 주문 모니터링, 주문 상태 변경, 주문 삭제, 테이블 이용 완료, 과거 내역 조회, 메뉴 CRUD |
| **핵심 니즈** | 실시간 주문 확인, 주문 상태 관리, 테이블 세션 처리, 메뉴 업데이트 |

---

## Persona 4: 직원 (Staff)

| 항목 | 내용 |
|------|------|
| **이름** | 최수진 (대표 직원) |
| **역할** | 매장 서빙/주방 직원 |
| **연령대** | 20~30대 |
| **기술 수준** | 기본~중간 |
| **목표** | 들어오는 주문을 빠르게 확인하고 처리 상태를 업데이트하고 싶다 |
| **동기** | 효율적인 업무 처리, 주문 누락 방지, 고객 대기 시간 최소화 |
| **불만 요소** | 주문 확인 지연, 복잡한 인터페이스, 불필요한 기능 노출 |
| **사용 환경** | 매장 내 공용 태블릿 또는 PC (브라우저 기반) |
| **접근 권한** | **주문 모니터링 + 주문 상태 변경** - 실시간 주문 확인, 주문 상태 변경 (대기중→준비중→완료) |
| **핵심 니즈** | 신규 주문 즉시 확인, 주문 상태 빠른 업데이트 |
