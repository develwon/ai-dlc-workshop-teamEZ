# 테이블오더 서비스 - 사용자 스토리

**분류 방식**: User Journey-Based (사용자 워크플로우 흐름)
**세분화 수준**: High-level (Epic 수준)
**수용 기준 형식**: Given-When-Then (BDD)
**우선순위 체계**: P1(필수), P2(중요), P3(선택)

---

## Journey 1: 고객 주문 여정 (Customer Order Journey)

### US-C01: 테이블 태블릿 자동 인증
**As a** 고객 (Customer)
**I want to** 테이블 태블릿에서 별도 로그인 없이 자동으로 인증되어
**So that** 즉시 메뉴를 보고 주문을 시작할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 고객 (김민수)
**요구사항 추적**: FR-C01

**Acceptance Criteria**:
- Given 관리자가 테이블 태블릿에 매장 식별자, 테이블 번호, 비밀번호를 1회 설정했을 때, When 태블릿 브라우저를 열면, Then 저장된 정보로 자동 로그인되어 메뉴 화면이 표시된다
- Given 자동 로그인 정보가 저장되어 있을 때, When 페이지를 새로고침하면, Then 로그인 상태가 유지되고 메뉴 화면이 다시 표시된다
- Given 저장된 로그인 정보가 유효하지 않을 때, When 자동 로그인을 시도하면, Then 초기 설정 화면이 표시되어 관리자가 재설정할 수 있다

---

### US-C02: 메뉴 조회 및 탐색
**As a** 고객 (Customer)
**I want to** 매장의 메뉴를 카테고리별로 탐색하고 상세 정보를 확인하여
**So that** 원하는 음식을 쉽게 찾아 선택할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 고객 (김민수)
**요구사항 추적**: FR-C02

**Acceptance Criteria**:
- Given 고객이 메뉴 화면에 있을 때, When 화면이 로드되면, Then 카테고리별로 분류된 메뉴가 카드 형태로 표시되고, 각 카드에 메뉴명, 가격, 이미지가 포함된다
- Given 메뉴 목록이 표시되어 있을 때, When 특정 카테고리를 선택하면, Then 해당 카테고리의 메뉴만 빠르게 필터링되어 표시된다
- Given 메뉴 카드가 표시되어 있을 때, When 메뉴 카드를 터치하면, Then 메뉴명, 가격, 설명, 이미지가 포함된 상세 정보가 표시된다
- Given 메뉴 화면이 표시되어 있을 때, When 터치 조작을 할 때, Then 모든 버튼과 터치 영역이 최소 44x44px 이상이다

---

### US-C03: 장바구니 관리
**As a** 고객 (Customer)
**I want to** 주문할 메뉴를 장바구니에 담고 수량을 조절하여
**So that** 주문 전에 선택한 메뉴를 확인하고 수정할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 고객 (김민수)
**요구사항 추적**: FR-C03

**Acceptance Criteria**:
- Given 메뉴 상세 화면에서, When 메뉴를 장바구니에 추가하면, Then 장바구니에 해당 메뉴가 추가되고 총 금액이 실시간으로 업데이트된다
- Given 장바구니에 메뉴가 있을 때, When 수량을 증가/감소시키면, Then 수량과 총 금액이 즉시 반영된다
- Given 장바구니에 메뉴가 있을 때, When 특정 메뉴를 삭제하면, Then 해당 메뉴가 장바구니에서 제거되고 총 금액이 재계산된다
- Given 장바구니에 메뉴가 있을 때, When 페이지를 새로고침하면, Then 장바구니 내용이 유지된다 (localStorage)
- Given 장바구니에 메뉴가 있을 때, When 장바구니 비우기를 실행하면, Then 모든 메뉴가 제거되고 총 금액이 0이 된다

---

### US-C04: 주문 생성
**As a** 고객 (Customer)
**I want to** 장바구니의 메뉴를 주문으로 확정하여
**So that** 매장에서 음식을 준비받을 수 있다

**우선순위**: P1 (필수)
**페르소나**: 고객 (김민수)
**요구사항 추적**: FR-C04

**Acceptance Criteria**:
- Given 장바구니에 1개 이상의 메뉴가 있을 때, When 주문 확정 버튼을 누르면, Then 주문이 서버에 전송되고 주문 번호가 표시된다
- Given 주문이 성공적으로 생성되었을 때, When 주문 성공 화면이 표시되면, Then 5초 후 자동으로 메뉴 화면으로 리다이렉트되고 장바구니가 비워진다
- Given 주문 전송 중 오류가 발생했을 때, When 서버 응답이 실패이면, Then 에러 메시지가 표시되고 장바구니 내용은 유지된다
- Given 주문이 생성될 때, When 주문 데이터가 서버에 전송되면, Then 매장 식별 정보, 테이블 식별 정보, 주문 메뉴 목록(메뉴명, 수량, 단가), 총 주문 금액, 세션 ID가 포함된다

---

### US-C05: 주문 내역 조회
**As a** 고객 (Customer)
**I want to** 현재 테이블 세션의 주문 내역과 상태를 확인하여
**So that** 주문이 정상적으로 접수되었는지, 현재 어떤 상태인지 알 수 있다

**우선순위**: P1 (필수)
**페르소나**: 고객 (김민수)
**요구사항 추적**: FR-C05

**Acceptance Criteria**:
- Given 현재 테이블 세션에 주문이 있을 때, When 주문 내역 화면을 열면, Then 주문 시간 순으로 정렬된 주문 목록이 표시되고, 각 주문에 주문 번호, 시각, 메뉴/수량, 금액, 상태가 포함된다
- Given 주문 내역 화면에서, When 주문 목록을 조회하면, Then 현재 테이블 세션의 주문만 표시되고 이전 세션(이용 완료 처리된) 주문은 제외된다
- Given 주문 상태가 변경되었을 때, When 주문 내역 화면을 새로고침하면, Then 최신 주문 상태(대기중/준비중/완료)가 반영된다

---

## Journey 2: 관리자 매장 운영 여정 (Admin Store Operation Journey)

### US-A01: 관리자 매장 인증
**As a** 관리자 (매장주/매니저/직원)
**I want to** 매장 식별자와 계정 정보로 로그인하여
**So that** 내 역할에 맞는 매장 관리 기능에 접근할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 매장주 (박영희), 매니저 (이준호), 직원 (최수진)
**요구사항 추적**: FR-A01

**Acceptance Criteria**:
- Given 관리자 로그인 화면에서, When 유효한 매장 식별자, 사용자명, 비밀번호를 입력하면, Then JWT 토큰이 발급되고 역할에 맞는 관리자 대시보드로 이동한다
- Given 로그인에 성공했을 때, When 16시간이 경과하면, Then 자동으로 로그아웃되고 로그인 화면으로 이동한다
- Given 로그인 상태에서, When 브라우저를 새로고침하면, Then 세션이 유지되고 관리자 대시보드가 다시 표시된다
- Given 잘못된 인증 정보로, When 반복적으로 로그인을 시도하면, Then 일정 횟수 이후 로그인 시도가 제한된다
- Given 로그인에 성공했을 때, When 대시보드가 표시되면, Then 사용자의 역할(매장주/매니저/직원)에 따라 접근 가능한 기능만 표시된다

---

### US-A02: 실시간 주문 모니터링
**As a** 관리자 (매장주/매니저/직원)
**I want to** 들어오는 주문을 실시간으로 테이블별 대시보드에서 확인하고 상태를 관리하여
**So that** 주문을 빠르게 처리하고 매장 운영 현황을 한눈에 파악할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 매장주 (박영희), 매니저 (이준호), 직원 (최수진)
**요구사항 추적**: FR-A02

**Acceptance Criteria**:
- Given 관리자 대시보드에서, When 새로운 주문이 들어오면, Then SSE를 통해 2초 이내에 해당 테이블 카드에 주문이 표시되고 시각적으로 강조된다
- Given 테이블별 그리드 대시보드에서, When 각 테이블 카드를 확인하면, Then 테이블 번호, 총 주문액, 최신 주문 미리보기가 표시된다
- Given 테이블 카드에서, When 주문 카드를 클릭하면, Then 전체 메뉴 목록이 포함된 주문 상세 정보가 표시된다
- Given 주문 상세 화면에서, When 주문 상태를 변경하면(대기중→준비중→완료), Then 상태가 즉시 업데이트되고 화면에 반영된다
- Given 대시보드에서, When 특정 테이블로 필터링하면, Then 해당 테이블의 주문만 표시된다

---

### US-A03: 테이블 관리
**As a** 관리자 (매장주/매니저)
**I want to** 테이블 설정, 주문 삭제, 이용 완료 처리, 과거 내역 조회를 수행하여
**So that** 테이블 운영을 효율적으로 관리하고 고객 회전을 원활하게 할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 매장주 (박영희), 매니저 (이준호)
**요구사항 추적**: FR-A03

**Acceptance Criteria**:
- Given 테이블 관리 화면에서, When 새 테이블을 설정하면(번호, 비밀번호), Then 테이블이 등록되고 태블릿에서 자동 로그인이 가능해진다
- Given 테이블에 주문이 있을 때, When 특정 주문을 삭제하면(확인 팝업 후), Then 해당 주문이 삭제되고 테이블 총 주문액이 재계산된다
- Given 고객이 식사를 마쳤을 때, When 테이블 이용 완료를 처리하면(확인 팝업 후), Then 현재 세션의 주문 내역이 과거 이력으로 이동하고, 테이블 주문 목록과 총 주문액이 0으로 리셋된다
- Given 이용 완료 처리 후, When 새 고객이 해당 테이블에서 주문하면, Then 이전 고객의 주문 내역 없이 새로운 세션으로 시작된다
- Given 테이블 관리 화면에서, When 과거 내역 버튼을 클릭하면, Then 해당 테이블의 과거 주문 목록이 시간 역순으로 표시되고 날짜 필터링이 가능하다

---

### US-A04: 메뉴 관리
**As a** 관리자 (매장주/매니저)
**I want to** 메뉴를 등록, 수정, 삭제하고 노출 순서를 조정하여
**So that** 매장의 메뉴를 최신 상태로 유지하고 고객에게 정확한 정보를 제공할 수 있다

**우선순위**: P1 (필수)
**페르소나**: 매장주 (박영희), 매니저 (이준호)
**요구사항 추적**: FR-A04

**Acceptance Criteria**:
- Given 메뉴 관리 화면에서, When 카테고리별 메뉴 목록을 조회하면, Then 등록된 모든 메뉴가 카테고리별로 분류되어 표시된다
- Given 메뉴 등록 화면에서, When 메뉴명, 가격, 설명, 카테고리, 이미지를 입력하고 저장하면, Then 새 메뉴가 등록되고 고객 화면에 반영된다
- Given 메뉴 등록/수정 시, When 필수 필드가 비어있거나 가격이 유효 범위를 벗어나면, Then 검증 오류 메시지가 표시되고 저장이 차단된다
- Given 메뉴 관리 화면에서, When 메뉴 이미지를 업로드하면, Then 이미지가 클라우드 스토리지(S3)에 저장되고 URL이 메뉴에 연결된다
- Given 메뉴 목록에서, When 메뉴 노출 순서를 변경하면, Then 변경된 순서가 저장되고 고객 화면에 반영된다
- Given 메뉴 관리 화면에서, When 메뉴를 삭제하면, Then 해당 메뉴가 목록에서 제거되고 고객 화면에서도 사라진다
