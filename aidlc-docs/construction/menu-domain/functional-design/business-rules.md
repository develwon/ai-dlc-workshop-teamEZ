# Business Rules - Unit 3: menu-domain

---

## 1. 메뉴 검증 규칙

| 규칙 ID | 규칙 | 검증 시점 | HTTP 상태 |
|---------|------|-----------|-----------|
| BR-M01 | name은 비어있을 수 없음 (1~100자) | 생성/수정 시 | 400 |
| BR-M02 | price는 0 이상의 정수 | 생성/수정 시 | 400 |
| BR-M03 | price는 10,000,000원 이하 | 생성/수정 시 | 400 |
| BR-M04 | categoryId는 해당 매장의 유효한 카테고리를 참조해야 함 | 생성/수정 시 | 400 |
| BR-M05 | description은 최대 500자 | 생성/수정 시 | 400 |
| BR-M06 | displayOrder는 0 이상의 정수 | 생성/수정 시 | 400 |
| BR-M07 | 메뉴 삭제 시 연결된 S3 이미지도 삭제 | 삭제 시 | - |
| BR-M08 | 메뉴 수정 시 새 이미지 업로드하면 기존 이미지 삭제 | 수정 시 | - |

---

## 2. 카테고리 검증 규칙

| 규칙 ID | 규칙 | 검증 시점 | HTTP 상태 |
|---------|------|-----------|-----------|
| BR-CT01 | name은 비어있을 수 없음 (1~50자) | 생성/수정 시 | 400 |
| BR-CT02 | 동일 매장 내 카테고리명은 고유해야 함 | 생성/수정 시 | 409 |
| BR-CT03 | displayOrder는 0 이상의 정수 | 생성/수정 시 | 400 |
| BR-CT-DEL01 | 카테고리에 메뉴가 존재하면 삭제 불가 | 삭제 시 | 409 |

---

## 3. 이미지 업로드 규칙

| 규칙 ID | 규칙 | 검증 시점 | HTTP 상태 |
|---------|------|-----------|-----------|
| BR-IMG01 | 이미지 파일 크기 최대 5MB | 업로드 시 | 400 |
| BR-IMG02 | 허용 파일 형식: JPEG, PNG, GIF, WebP | 업로드 시 | 400 |
| BR-IMG03 | 파일명은 UUID 기반으로 고유하게 생성 | 업로드 시 | - |
| BR-IMG04 | S3 삭제 실패 시 비즈니스 로직 중단하지 않음 (로그만 기록) | 삭제 시 | - |

## 5. 매장 격리 규칙

| 규칙 ID | 규칙 | 적용 대상 |
|---------|------|-----------|
| ISO-01 | 모든 메뉴/카테고리 데이터 접근은 storeId로 필터링 | 모든 조회/수정/삭제 |
| ISO-02 | JWT의 storeId와 요청 데이터의 storeId 일치 검증 | 모든 API 엔드포인트 |
| ISO-MENU01 | 메뉴의 categoryId는 동일 매장의 카테고리만 참조 가능 | 메뉴 생성/수정 |

---

## 6. 에러 처리 규칙

| 시나리오 | HTTP 상태 | 에러 메시지 |
|----------|-----------|-------------|
| 메뉴 미존재 | 404 | "메뉴를 찾을 수 없습니다" |
| 카테고리 미존재 | 404 | "카테고리를 찾을 수 없습니다" |
| 카테고리명 중복 | 409 | "이미 존재하는 카테고리명입니다" |
| 카테고리에 메뉴 존재 시 삭제 시도 | 409 | "메뉴가 존재하는 카테고리는 삭제할 수 없습니다" |
| 입력 검증 실패 | 400 | Bean Validation 메시지 |
| 이미지 크기 초과 | 400 | "이미지 파일 크기는 5MB를 초과할 수 없습니다" |
| 이미지 형식 오류 | 400 | "허용되지 않는 파일 형식입니다 (JPEG, PNG, GIF, WebP만 허용)" |
| 권한 부족 | 403 | "해당 기능에 대한 권한이 없습니다" |
| 매장 격리 위반 | 403 | "접근 권한이 없습니다" |
